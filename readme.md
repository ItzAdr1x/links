# My Linktree

A small, fully customizable link page with no build step or dependencies.

## Files

| File | Purpose |
|---|---|
| `config.js` | **Customize everything here:** name, bio, avatar, colors, and links |
| `index.html`, `style.css`, `app.js` | The website itself (you usually don’t need to edit these) |

## View locally

Open `index.html` in your browser.

## Publish with GitHub Pages

1. Create a new **public** repository on GitHub, for example `linktree`.
2. Upload all the files from this folder and commit them.
3. In the repository, go to **Settings → Pages → Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: `main`, folder: `/ (root)` → click **Save**
4. After about a minute, your site should be available at:

   `https://YOUR-USERNAME.github.io/linktree/`
